# Systems as Attack Vectors

## Overview / Objective
Move from human-targeted attacks to how threat actors exploit technology and infrastructure.

## Platform & date
| Platform | Module | Completed |
|---|---|---|
| TryHackMe | Systems as Attack Vectors | 1 September 2026 |

## What I did / key steps
- **System value:** how targets, from personal devices to critical enterprise servers and cloud platforms, have different value to attackers
- **Attack vectors:** human-led errors (weak passwords, malicious USBs), software vulnerabilities and supply-chain attacks
- **Vulnerabilities vs misconfigurations:** software bugs (CVEs, zero-days) and patch management, compared with IT setup mistakes such as insecure cloud configurations and default settings
- **Mitigation and defence:** penetration testing, configuration audits, network access restrictions and vulnerability scanning

## Key concepts
- Vulnerability (a bug that needs a patch) vs misconfiguration (a setup mistake that needs a configuration audit)
- Supply-chain risk

## Findings / outcome
Module completed.

## Lessons learned
Defending systems means covering every angle: patching, configuration hygiene, access restriction and continuous scanning.
